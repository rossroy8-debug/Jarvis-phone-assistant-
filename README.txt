JARVIS BUILD 03 — ANDROID WEB APP STARTER
Includes futuristic UI, voice recognition and speech (browser support required), experimental Hey JARVIS mode, basic commands, website shortcuts, local notes, local reminders and PWA files.

LIMITATIONS:
- This is a browser-based PWA, not a native Android app.
- Wake-word listening is experimental and cannot reliably run with the phone locked/backgrounded.
- Reminders are best-effort; browser closure or battery restrictions may prevent alerts.
- Full AI chat is not connected. A secure backend is required. Never place private API keys in public code.
- Direct installed-app control and Android system actions require native Android development and permissions.
- Microphone and install features generally require HTTPS.

PUBLISH:
Upload these files to the root of your GitHub repository. In GitHub open Settings > Pages, choose Deploy from a branch, select main and /(root), then Save. Wait for HTTPS site, open in Chrome on Android and choose Install app/Add to Home screen. Allow microphone/notifications only if desired.
